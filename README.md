# 给可可露的圣诞节约会邀请

这是一个单文件、移动端优先的 H5 互动邀请。双击 `index.html` 即可在浏览器打开，不需要安装依赖或启动服务器。

## 互动流程

1. 拆开圣诞邀请。
2. 选择接受，或经过 6 次温和的再次询问。
3. 接受后进行二次确认。
4. 从 6 个约会项目中选择 1–2 项。
5. 回答所选项目的细节。
6. 选择日期、时间和大致地点。
7. 生成一份可一键复制的约会清单。

## 修改名字

打开 `index.html`，找到：

```js
const CONFIG = {
  invitee: "可可露",
  sender: "我",
};
```

直接修改 `invitee` 即可替换女主角名字。

## 发布到 GitHub Pages

1. 在 GitHub 新建一个公开仓库。
2. 上传 `index.html`，不要把本地预览截图作为网页依赖。
3. 打开仓库的 `Settings` → `Pages`。
4. 在 `Build and deployment` 中选择 `Deploy from a branch`。
5. 分支选择 `main`，目录选择 `/ (root)`，保存。
6. 等待 GitHub 生成公开链接，再把链接发到微信。

## 隐私

页面不会上传、保存或发送任何选择内容。约会清单只在浏览器本地生成，并由用户手动复制。

## 背景音乐

页面使用 Apple Music 官方公开提供的 30 秒试听资源播放 Carpenters 的
《(They Long To Be) Close To You》。

由于歌曲版权和浏览器自动播放限制，页面会先进入曲目卡片；点击“拆开这封邀请”或右下角音乐按钮后再尝试播放。试听为平台公开预览，不下载或重新分发受版权保护的完整歌曲文件。
